Privacy policy

Last updated: 27 September 2026

About this app

local-finance-tracker is a private budgeting application used by its owner on their own Mac. It is not a public service and is not offered to other users.

Bank information

If the owner enables Open Banking, local-finance-tracker requests read-only account and transaction information for the owner's linked NatWest account through Enable Banking. The owner approves access through NatWest and can withdraw consent using NatWest's consent controls. local-finance-tracker does not initiate payments.

Information returned to local-finance-tracker may include account names and identifiers, balances, transaction dates, amounts, descriptions, and references. The app stores imported transactions and categories in its local SQLite database. It also saves connection and consent-session details in a local file. The app's categorisation and review features operate locally.

Where information goes

Bank connection and data requests are made to Enable Banking, which provides the Open Banking connection to NatWest. NatWest handles the account authorisation and supplies the permitted data. During authorisation, Cloudflare Tunnel forwards the HTTPS callback to the local local-finance-tracker process; the callback contains temporary authorisation parameters, not transaction history or bank login credentials. The local-finance-tracker app does not intentionally upload the resulting transaction database to a website or cloud service. Anyone who can access this Mac, the project folder, or a backup may be able to access locally stored data.

This policy page is hosted by GitHub Pages. GitHub may process technical information about visits to the page under its own Privacy Statement. Bank data is not published on this website.

Retention and deletion

Information remains in the local database and connection file until the owner deletes those files. Copies may remain in the owner's backups or in any statement files the owner has saved. To stop future access, the owner can revoke the consent with NatWest. To remove local copies, stop local-finance-tracker and delete the relevant files from its data/, archived/, and backup folders.

Security

The Enable Banking private key should be kept outside the project folder and protected by the owner. local-finance-tracker is designed to run locally, but the owner is responsible for securing the Mac, files, and backups.

Contact

For questions about this personal application, contact its owner through the GitHub profile.
